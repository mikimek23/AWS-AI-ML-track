# Wine Analysis

A simple Python and Jupyter Notebook project for exploring red-wine quality data.

## Overview

This project analyzes red-wine samples to explore how chemical properties such as acidity, sugar, alcohol, and sulphates relate to wine quality. The notebook cleans the data, summarizes key patterns, and presents a processed data.

## Files

- `wine_analysis.ipynb` — analysis notebook and visualizations
- `winequality-red.csv` — source dataset
- `processed_wine.csv` — processed dataset

## Run the project

1. Create and activate a Python virtual environment (optional).
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```
4. Open `wine_analysis.ipynb` and run all cells in order.

## Requirements

- Python 3
- Jupyter Notebook
